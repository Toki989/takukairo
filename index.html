卓回廊

LOCAL / TEST

あなたの回廊を、ローカルで確認する。

作品、PC、卓の記録、画像、Importを、実際に保存しながら確認できます。

01 — START

アプリを起動

このファイルと同じフォルダーの
起動.cmdをダブルクリックしてください。

起動が完了すると、ブラウザで卓回廊が開きます。初回は準備に数分かかる場合があります。

すでに起動している場合は、「卓回廊を開く」ボタンから開けます。

02 — OPEN

画面を開いて確認

ログイン画面では「固定テストユーザーでログイン」を選びます。

卓回廊を開く　↗
作品・卓 PL・PC Import

確認を終えるとき

同じフォルダーの停止.cmdをダブルクリックします。保存した記録・画像・Importの途中保存は、停止しても残ります。

このHTMLはアプリを開く入口です。保存・Importを使う間は、ローカルアプリを起動しておきます。HTMLだけを別の場所へ移すのではなく、卓回廊のフォルダーを保持してください。
