## 根拠

- `卓回廊_Codex実装正本_2026-10-08_R5.1.12_最終Contract補強版.md` の優先順位に従い、Part Aの上書きを確認したうえで、Part C §8、§10〜12、§17.5、§33を参照した。
- Part C §17では、HomeをScenario美術館とし、Header → Collection Summary → Search / Filter / Sort → Scenario Galleryを基本構成とする。§17.5は同一比率の強制と不要なcropを避け、通常情報を作品画像・作品名・作者とし、卓数やFavorite操作はHover / Focusで静かに提示する。
- `仕様書（テスト用）参照資料/TRPG活動履歴管理Webサービス_最新統合正本_2026-09-28_確定版_フロント制作補強修正版(3).md` N-02A〜Cを照合。画像をTrailer Artとして尊重するCurated Gridが確定方針である。

- v5プロトタイプは幅の異なる作品を配置する参考に限定し、画像を分類比率へcropする実装は引き継がない。

## 修正

1. Home専用の `ScenarioGallery` を追加した。PC Collectionの画像表示とはCSSを分け、Homeでの固定高270px / 180pxを解除した。
2. 読み込んだ画像の自然寸法に応じて、縦長・正方形付近・横長を分類する。画像は常に幅100%・高さautoで全体を表示し、分類用の比率へ加工しない。
3. 横長作品は2列分を使う。列数はDesktop 4 / Tablet 3 / Mobile 2とし、画面幅に応じて配置を変える。
4. 空きを埋めるために作品順を変えない。選択したSortとDOM・視覚・Keyboardの読み順を一致させる。
5. 通常表示は作品名・作者を中心とし、卓数と未Favoriteの操作はHover / Focusで表示する。Favorite済みの星は小さく常時表示する。Hoverのない端末では補助情報と操作を表示し、タップで利用できるようにする。
6. お気に入り操作を画像の外へ移し、作品の構図を覆わないようにした。44pxの操作領域と共通Focus Ringを維持する。
7. 体験版Homeの大きな紹介欄を外し、Galleryが主役になる基本構成へ戻した。体験版の説明とリセットは引き続き上部から利用できる。

比率分類の0.8 / 1.2、列数、具体的な余白は今回の実装調整値であり、新しい正式FieldやBusiness Ruleではない。画像の寸法・分類をDBやPublic DTOへ追加していない。画像そのものと保存済みの体験データは変更しない。

## 余白・Hoverの再照合

ユーザーからの追加指摘に基づき、Part C §13・§17.5と、VisualResponsiveAccessibility資料§4.4・§5.5を再照合した。

- 基本間隔は参考資料の24pxに対して32pxだった。さらに通常のGrid行が最も高い作品に引っ張られ、Desktopの短い作品直下には約282pxの空きが発生していた。
- Hoverで卓数・Favorite操作を示す内容は仕様に沿っていた。一方、補助情報が即時に切り替わり、資料にある約260msの演出が反映されていなかった。作品名のHoverとKeyboard Focusでも表現が揃っていなかった。

修正内容:

1. 作品ごとの実寸をResizeObserverで測り、細かいGrid行への占有数を更新する。画像読み込み・画面幅・文字の折り返しに追従し、長い作品と同じ行にいることだけを理由とする大きな空きを減らした。
2. 作品間隔は24pxを基準とする。4pxの行単位への丸めを含め、上記箇所の実測は約27pxになった。横長作品の2列占有、元画像比率、DOMと視覚上のSort順は維持する。
3. 補助情報は260ms / cubic-bezier(.2,.7,.2,1)でフェード表示する。作品名のHover / Focus表現を揃える。画像の拡大・CropやCard全体の浮き上がりは追加しない。
4. 卓数とFavorite操作を専用の44px操作行に収め、作者名との重なりと、卓数クリックで作品詳細へ遷移する状態を解消した。表示切替で作品の高さは変えない。
5. Reduced Motion時は即時表示に切り替えて機能を維持する。Touch端末の補助操作は常時利用可能とする。

仕様書は特定のMasonry方式を必須にしていない。今回の行単位と詰め方はCurated Gridの範囲内で過剰な空白を調整する実装判断であり、残る余白すべてを仕様違反と判定したものではない。異なる幅の作品とSort順を維持するための空きは残る。

検証結果: TypeScript検査、通常版・体験版ビルド、ブラウザ検査17件が成功。追加検査では、画面幅を変更しても作品が重ならないこと、短い作品下の間隔、Hoverで配置が動かないこと、Focus、Reduced Motion、Favorite操作を確認した。
